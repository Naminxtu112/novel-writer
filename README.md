# Novel Deadline Editor v6

## 今回の変更
- 締切は1件だけでも利用可能（最大3件）
- 締切名は作品設定から自由に変更可能（例: 「標準」→「A出版」）
- 日時未設定の締切は上部に表示しない
- 本文 / アウトライン / キャラ設定 を上部タブで切替
- 本文では「第1章」「第2章」などの章タブで直接移動
- アウトライン・キャラ設定は任意で、本文文字数・ページ数・進捗には影響しない
- 通常の本文TXTにはアウトライン・キャラ設定を含めない
- アウトライン、キャラ設定は必要な場合だけ個別TXTとして出力可能
- 作品削除、章削除を維持
- 新規作品作成batchに対応するため Firestore Rules の chapter create を `getAfter()` に修正

## GitHub Pagesで置き換えるファイル
- `index.html`
- `style.css`
- `app.js`
- `404.html`

`firebase-config.js` は既存のFirebase設定値が入っているものをそのまま使ってください。今回の配布版では、ユーザー提供どおり設定値を空欄にしています。

## Firebase側で更新するもの
Firebase Console → Firestore Database → ルール で `firestore.rules` の内容に置き換えて「公開」してください。

## TXT出力
- 「本文を出力」: 章本文のみ。章見出し・空行などのオプションが適用されます。
- 「アウトラインを出力」: `<作品名>_アウトライン.txt`
- 「キャラ設定を出力」: `<作品名>_キャラ設定.txt`

## 注意
作品削除・章削除はFirestoreから実データを削除します。削除の取り消し機能はありません。
