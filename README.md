# Novel Deadline Editor v7.4

## v7.2
- アウトラインのライン名を図上でダブルクリックして直接編集
- ラインを右クリック → ポップアップからイベントを追加
- イベントをドラッグ移動、右クリック/ダブルクリックで直接編集
- イベント編集ポップアップから接続先を選び、分岐・合流を追加
- 左端に時系列ラベルを追加し、上下にドラッグ移動・直接編集
- 下部のイベント一覧/接続一覧を廃止
- キャラクター相関図のキャラノードをドラッグ配置
- 相関図上で関係線を直接追加・編集
- 関係線は実線/点線/一点鎖線、色変更、A→B/B→A/双方向矢印に対応
- 既存v7.1データは自動互換

## 更新するファイル
- index.html
- app.js
- style.css
- 404.html

Firebase Rulesは現在正常に動作しているv6.1以降のものをそのまま使用できます。


## v7.4 追加
- 同じ2キャラ間に複数の関係線がある場合、自動で曲線をずらして描画
- A→B と B→A を別々の側へ配置
- 各関係ラベルも線に追従してずらし、重なりを回避
- 3本以上ある場合も等間隔に自動配置


## v7.4
- 同一キャラペアの複数関係線を、画面上の上下方向へ固定間隔で分離
- 関係ラベルも独立した上下スロットへ配置し、同一ペア内で重なりにくい表示へ変更
- A→B と B→A を別関係として登録した場合も上下に分離


## v7.5
- 同じ2キャラ間の複数関係を独立した上下スロットへ配置
- A→B / B→A も同一ペアとしてまとめ、ラベルを別Y座標に固定
- 関係ラベルの高さより大きい間隔を確保し、テキストボックスの重なりを防止
- 関係線自体も別の曲率スロットへ分離
- 2本、3本、4本以上でも中央基準で上下に等間隔配置


## v7.6 スマホ操作対応
- PCの右クリック／ダブルクリック操作を維持
- スマホでは1回タップで選択、同じ対象をもう1回タップで編集
- 560ms長押しで右クリック相当の編集メニュー
- ドラッグ開始時は長押し判定を解除し、誤操作を防止
- アウトラインのライン空白を長押ししてイベント追加
- キャラクター関係線・アウトライン接続線の透明タップ領域を拡大
- キャラクター関係追加モードはスマホのタップ操作に対応
- 図の横スクロールとブラウザ標準のピンチズームを維持


## v7.7
- キャラクター相関図に拡大・縮小UIを追加
- スマホで2本指ピンチによるズームに対応
- 「全体表示」「100%」「＋」「－」ボタンを追加
- 初回表示時は相関図全体が収まりやすい倍率へ自動調整


## v7.8
- アウトラインの時系列フローチャートにも拡大・縮小UIを追加
- スマホで2本指ピンチによるズームに対応
- 「全体表示」「100%」「＋」「－」ボタンを追加
- 初回表示時はフローチャート全体が収まりやすい倍率へ自動調整
