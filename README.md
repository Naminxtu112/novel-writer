# Novel Deadline Editor v7.9

GitHub Pages + Firebase で動作する、長編執筆向けの進捗管理・本文編集Webアプリです。
PCとスマホの両方から同じ作品を編集でき、本文、締切、文字数進捗、アウトライン、キャラクター設定を1つの作品URL内で管理します。

---

## 1. 主な機能

- ログインID + 編集パスワードによるユーザー認証
- 作品ごとの専用URL
- 複数作品の作成・削除
- 複数章の作成・名称変更・削除
- 本文の自動保存
- Firebase Firestoreへの同期
- ローカルストレージへの一時保存
- 締切カウントダウン
- 最大3件までの締切登録
- 締切名称の自由変更
- 目標文字数・進捗率・残り文字数表示
- 1日あたり必要文字数の表示
- 当日執筆文字数の表示
- ページ数換算
- 校閲・表記ゆれチェック
- TXT出力
- アウトラインメモ
- 時系列フローチャート
- キャラクターシート
- キャラクター関係図
- PC / スマホ両対応
- フローチャート・相関図の拡大縮小

---

## 2. 画面構成

作品を開くと、上部タブから以下の3画面を切り替えられます。

### 本文
章ごとの本文を編集するメイン画面です。

### アウトライン
本文とは独立した補助ページです。

- アウトラインメモ
- 時系列フローチャート

を管理します。

### キャラ設定
本文とは独立した補助ページです。

- キャラクターシート
- キャラクター関係図
- 自由メモ

を管理します。

アウトライン・キャラ設定の内容は、本文の文字数や通常の本文TXT出力には含まれません。

---

## 3. 作品管理

### 新規作品
作品一覧から「＋ 新しい作品」を押して作成します。

設定項目：

- 作品名
- よみ（任意）
- URL名
- 目標文字数
- 締切1〜3件

URL名は作品の専用URLに使用されます。

### 作品削除
作品一覧から作品単位で削除できます。

削除すると、本文、章、アウトライン、キャラクター設定を含む作品データ全体が削除されます。

---

## 4. 章管理

本文画面上部に章タブが表示されます。

- 「＋ 章追加」で新しい章を作成
- 章名をダブルクリックして名称変更
- × ボタンで章削除

最低1章は残る仕様です。

---

## 5. 本文エディタ

本文は章ごとに保存されます。

入力後は一定時間後に自動保存され、画面下部に保存状態が表示されます。

保存状態：

- 保存中…
- ローカル保存済み / クラウド待機
- Firebase同期済み
- クラウド保存失敗 / ローカルには保存済み

Firebaseへの保存前にもローカルストレージへ一時保存されます。

---

## 6. 締切管理

締切は最大3件まで登録できます。

初期名称：

- 早割り
- 標準
- 特急

名称は設定画面から自由に変更できます。

例：

- A出版
- Bイベント
- 最終締切

1件だけ設定して使用することも可能です。

設定済みの締切のうち、どれをメイン表示にするか選択できます。

画面上部には、選択中の締切までの残り時間が

`○日 HH:MM:SS`

形式で表示されます。

---

## 7. 進捗表示

画面下部には以下を表示します。

- 現在文字数
- 目標文字数
- 達成率
- 残り文字数
- 推定ページ数
- 当日執筆文字数
- 締切までに必要な1日あたり文字数
- 保存状態

---

## 8. ページ数換算

設定画面からページ換算条件を変更できます。

初期プリセット：

### A6
- 40字 × 16行

### A5
- 57字 × 23行

### カスタム
任意の

- 1行文字数
- 1ページ行数
- フォントサイズ

を指定できます。

「改行を考慮してページ推定する」をONにすると、実際の改行を考慮したページ数推定を行います。

---

## 9. 校閲機能

本文画面の「校閲」ボタンから、表記ゆれ・指定語句を確認できます。

初期ルール例：

- 出来る → できる
- 下さい → ください
- 致します → いたします
- と言う → という
- 事 → こと
- 様な → ような

設定画面から独自ルールを追加できます。

---

## 10. TXT出力

「TXT出力」から本文をテキストファイルとして保存できます。

本文出力では以下を選択できます。

- 章見出しを含める
- 章間に空行を入れる
- 連続空行を1つにする
- 行頭の空白を削除

また、補助ページは本文とは別ファイルとして出力できます。

- アウトラインTXT
- キャラ設定TXT

---

# アウトライン

## 11. アウトラインメモ

プロット、章構成、伏線、アイデアなどを自由記述できます。

本文とは別管理です。

---

## 12. 時系列フローチャート

複数ラインを使い、物語の並行進行・分岐・合流を可視化できます。

主な要素：

- ライン
- イベントノード
- ノード間の接続
- 時系列ラベル

### ライン
「＋ ライン追加」で増やせます。

PC：
- ライン名をダブルクリックして編集
- ライン内の空白を右クリックしてイベント追加

スマホ：
- タップで選択
- 再タップまたは長押しで編集
- ライン空白の長押しでイベント追加

### イベント
イベントノードはドラッグして自由に移動できます。

編集メニューから

- イベント本文編集
- 接続先設定
- 削除

を行います。

### 分岐・合流
1つのイベントから複数イベントへ接続できます。
複数イベントを1つのイベントへ接続することも可能です。

### 時系列ラベル
左側に大まかな時間区分を置けます。

例：

- 春
- 1年前
- 第1週
- 翌朝

ラベルは上下にドラッグして移動できます。

### PNG出力
フローチャートをPNG画像として出力できます。

---

## 13. フローチャートの拡大縮小（v7.9）

フローチャート上部に以下の操作があります。

- 全体表示
- －
- 現在倍率表示
- ＋
- 100%

### 全体表示
図全体がプレビュー領域内に収まるよう、幅と高さの両方を基準に自動縮小します。

大規模なフローチャートにも対応するため、縮小下限は約8%です。

### PC

- ＋ / － ボタン
- 100%ボタン
- Ctrl + マウスホイール

で拡大縮小できます。

### スマホ

- ＋ / － ボタン
- 100%ボタン
- 2本指ピンチ

で拡大縮小できます。

拡大後はプレビュー領域内をスクロールして移動できます。

v7.9では、CSSの `min-width:100%` によって縮小が阻害される問題を修正し、SVG自体を画面幅未満まで縮小できるようにしています。

# キャラクター設定

## 14. キャラクターシート

「＋ キャラ追加」でキャラクターを追加できます。

初期項目：

- 名前
- 性格
- 容姿
- 背景
- 役割
- メモ

各項目名自体も自由に変更できます。

キャラクターシートは削除可能ですが、最低1つは残る仕様です。

---

## 15. キャラクター関係図

登録したキャラクターをノードとして配置し、人物関係を図示できます。

キャラクターノードはドラッグして自由に配置できます。

### 関係追加
「＋ 関係追加」を押し、接続する2人を順番に選択します。

スマホでもキャラクターを順番にタップして関係を作成できます。

### 関係線設定
各関係線には以下を設定できます。

- 関係名
- 線種
- 色
- A → B
- B → A
- 双方向

線種：

- 実線
- 点線
- 一点鎖線

---

## 16. 同じ2人の間に複数関係がある場合

例：

- A → B：尊敬
- B → A：警戒
- A → B：秘密を共有

のように同じ2キャラ間へ複数関係を登録できます。

v7.5以降では、同じキャラペアの関係を自動的に上下スロットへ分離します。

- 2本：上下2段
- 3本：上・中央・下
- 4本以上：中央を基準に等間隔配置

関係線だけでなく、関係名のテキストボックスも別のY座標へ配置されるため、A→B / B→A のラベルが同じ位置で重ならないようになっています。

---

相関図上部に以下があります。

- 全体表示
- －
- 現在倍率表示
- ＋
- 100%

### PC

- ＋ / －
- 100%
- Ctrl + マウスホイール

### スマホ

- ＋ / －
- 100%
- 2本指ピンチ

拡大後はプレビュー領域内をスクロールできます。

# PC / スマホ操作

## 18. PC操作

図編集では主に以下を使用します。

- 左クリック
- ドラッグ
- ダブルクリック
- 右クリック

右クリックまたはダブルクリックで直接編集メニューを開けます。

---

## 19. スマホ操作

v7.6以降、図編集をタッチ操作に対応しています。

基本操作：

- 1回タップ：選択
- 同じ対象をもう1回タップ：編集
- 約560ms長押し：右クリック相当
- ドラッグ：ノード移動
- 2本指ピンチ：図の拡大縮小

ドラッグが始まった場合は長押し判定を解除し、誤操作を防ぎます。

細い関係線や接続線には、見た目より太い透明タップ領域を設定して、スマホでも選択しやすくしています。

---

# 保存・同期

## 20. Firebase

主なデータはFirestoreに保存されます。

- 作品情報
- 締切
- ページ設定
- 校閲ルール
- アウトライン
- フローチャート
- キャラクターシート
- キャラクター関係
- 各章本文

Firebase Authenticationを使ってログインします。

---

## 21. ローカル一時保存

編集内容はFirebase送信前にもブラウザのローカルストレージへ一時保存されます。

クラウド保存に失敗した場合でも、画面上では

`ローカルには保存済み`

と表示されます。

---

# GitHub Pages

## 22. 必要ファイル

基本構成：

- `index.html`
- `app.js`
- `style.css`
- `firebase-config.js`
- `404.html`
- `README.md`

`firebase-config.js` には使用中のFirebaseプロジェクト設定を記述してください。

---

## 23. 404.html

GitHub Pages上で作品別URLへ直接アクセスした場合でもアプリへ戻れるよう、404.htmlから元のパスをクエリとして引き継ぎます。

これにより、

`/write/作品slug`

形式のURLを直接開ける構成になっています。

# v7.9 仕様上のポイント

## 24. v7.9での主な修正

- PC / スマホ両対応
- キャラクター関係図のピンチズーム
- フローチャートのピンチズーム
